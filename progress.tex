\section*{Scope and provenance}
The boundary-driven XXZ chain is evolved as a Julia matrix product density
operator using ITensors.jl and ITensorMPS.jl.
The package includes dependency metadata, readable source, README, example,
benchmark, tests, an executed Jupyter notebook, and this note and a model
note. No connected GitHub package or code was reused. The model was
motivated by Prosen's boundary-driven XXZ work and implemented independently
using the documented ITensorMPS gate API. Existing dependencies retain
their upstream licenses. The unrelated \texttt{boundary\_xxz\_reference}
directory was not changed.
\section*{Commands and results}
Using Julia 1.13.1, ITensors 0.9.14, ITensorMPS 0.3.23, an offline
writable depot, and one BLAS thread, the test command (shown without
machine-specific depot and executable paths)
\begin{verbatim}
JULIA_PKG_OFFLINE=true OPENBLAS_NUM_THREADS=1 julia --project=. test/runtests.jl
\end{verbatim}
passed 33 of 33 tests in four groups. The analogous commands for
\texttt{example.jl} and \texttt{benchmark.jl} completed. At $t=0.4$,
$dt=0.02$, the maximum entrywise density differences from independent
dense Lindblad evolution for $N=2,3,4$ were respectively
$4.63\times10^{-9}$, $1.97\times10^{-6}$, and $7.52\times10^{-7}$
in the executed notebook. The sample density matrices had traces within
$10^{-7}$ of one and positive minimum Hermitian eigenvalues
$0.176184,0.087559,0.043550$. The model's $J=\Delta=0$ edge
magnetizations matched $\pm\mu(1-e^{-2\gamma t})$ to $10^{-11}$.

For $N=3$ at $t=0.5$, the Frobenius errors against dense evolution were
$1.263\times10^{-4}$ at $dt=0.1$, maximum bond dimension 16;
$7.904\times10^{-6}$ at $dt=0.025$, maximum bond dimension 16; and
$2.424\times10^{-2}$ at $dt=0.025$, maximum bond dimension 2.
A finite-difference continuity check passed at tolerance $2\times10^{-3}$.
At $t=12$, $N=3$, the two currents were $0.382790$ and $0.382643$;
the left and right source terms were $0.382704$ and $-0.382718$.
The maximum MPDO versus trace-constrained dense NESS density difference
was $1.568\times10^{-5}$; the dense NESS residual was below $10^{-12}$.

Four Julia notebook cells were executed sequentially in one Julia process;
their standard output is saved in \texttt{xxz\_tutorial.ipynb}. The notebook
also confirmed that \texttt{density\_mpo} returns an
\texttt{ITensorMPS.MPO}. A warmed local benchmark for $t=1$, $dt=0.05$,
maximum bond dimension 32 took $0.020$ s for $N=4$ and $0.037$ s
for $N=6$. These short timings are illustrative and exclude Julia startup.
No commit, push, publication, or release was performed.

\section*{Limitations}
The gate split has finite-step error. Compression can perturb trace,
Hermiticity, and positivity, so users should refine time step, cutoff,
and bond dimension. The dense reference is capped at four sites and
full density materialization at five. The late-time MPO evolution is a
finite-time approximation to the NESS, not a variational steady-state
solver. Large-chain convergence and transport scaling were not claimed.
